# Case graphics: embed codes

Four graphics serve all five case pages. Each reads its content from `data.js`, chosen by `?case=01` to `?case=05` in the address.

Paste each code below that section's heading on the case page, in place of the text or table it replaces. Heights adjust to screen width with inline CSS, so no script is needed on the page, and frames scroll if a reader opens several items.
